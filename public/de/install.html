CatchCount › Installation

So installierst du CatchCount auf Handy und Computer

CatchCount ist eine Web-App: Sie wird in wenigen Sekunden aus dem Browser installiert und danach über ein eigenes Symbol im Vollbild gestartet – auch ohne Internet nutzbar.

Android (Chrome)

  1. Öffne catchcount.app in Chrome.
  2. Tippe oben rechts auf das Menü ⋮.
  3. Wähle „App installieren“ (oder „Zum Startbildschirm hinzufügen“).
  4. Bestätige. Das Symbol erscheint auf dem Startbildschirm.

iPhone und iPad (Safari)

  1. Öffne catchcount.app in Safari – in anderen Browsern auf dem iPhone ist die Installation nicht verfügbar.
  2. Tippe auf die Schaltfläche „Teilen“ (Quadrat mit Pfeil nach oben).
  3. Wähle „Zum Home-Bildschirm“.
  4. Bestätige mit „Hinzufügen“.

Computer (Chrome oder Edge)

  1. Öffne catchcount.app.
  2. Klicke am Ende der Adressleiste auf das Installationssymbol oder wähle das Menü → „CatchCount installieren“.

Hilfreiche Berechtigungen

  • Standort – um den Ort des Fangs automatisch zu speichern.
  • Benachrichtigungen – für die Erinnerung beim Timer der Rute.

Die App muss nicht aus einem Store heruntergeladen werden, deshalb aktualisiert sie sich selbst, wenn es eine neue Version gibt. Melde dich nach der Installation in deinem Konto an, solange du Internet hast. Danach funktioniert sie auch ohne Verbindung.

Häufige Fragen

Warum sehe ich in Chrome nicht „App installieren“?
Aktualisiere Chrome und lade die Seite neu. Ist die App bereits installiert, wird die Option nicht angezeigt.
Braucht die App viel Speicherplatz?
Nein. Die Installation ist klein, und die Fotos deiner Fänge werden komprimiert, bevor sie gespeichert werden.

Führe schon heute dein Fangtagebuch.

Die Registrierung dauert eine Minute, und die App wird direkt aus dem Browser installiert.
