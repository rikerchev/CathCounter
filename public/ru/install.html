Как установить CatchCount на телефон и компьютер

CatchCount — это веб-приложение: оно устанавливается из браузера за несколько секунд, а затем запускается с собственной иконки, на весь экран и с работой без интернета.

Android (Chrome)

  1. Откройте catchcount.app в Chrome.
  2. Коснитесь меню ⋮ в правом верхнем углу.
  3. Выберите «Установить приложение» (или «Добавить на главный экран»).
  4. Подтвердите. Иконка появится на главном экране.

iPhone и iPad (Safari)

  1. Откройте catchcount.app в Safari — в других браузерах на iPhone установка недоступна.
  2. Коснитесь кнопки «Поделиться» (квадрат со стрелкой вверх).
  3. Выберите «На экран “Домой”».
  4. Подтвердите кнопкой «Добавить».

Компьютер (Chrome или Edge)

  1. Откройте catchcount.app.
  2. В конце адресной строки нажмите на значок установки или выберите меню → «Установить CatchCount».

Разрешения, которые помогают

  • Местоположение — для автоматической записи места улова.
  • Уведомления — для напоминания при работе таймера удилища.

Приложение не нужно скачивать из магазина, поэтому оно обновляется само, когда выходит новая версия. После установки войдите в профиль, пока есть интернет. Затем оно работает и без связи.

Частые вопросы

Почему я не вижу «Установить» в Chrome?
Обновите Chrome и перезагрузите страницу. Если приложение уже установлено, этот пункт не отображается.
Занимает ли приложение много места?
Нет. Установка небольшая, а фотографии уловов сжимаются перед сохранением.
